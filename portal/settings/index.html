Endpoint Settings

How this works

Every use case in this portal sends chat requests through a single client-side client that tries endpoints in a fixed order:

  1. 1. Nutanix Enterprise AI — tried first, always.
  2. 2. OpenRouter — used only if the primary endpoint fails or isn’t configured.

These settings are saved only in this browser (localStorage) — they are never sent to or stored on the server. Clearing your browser data or using a different device/browser will reset them.

1 · Primary

Nutanix Enterprise AI

Leave unchecked to use this demo’s built-in server-side key via the local proxy (works out of the box, no key required). Check this to call the endpoint directly from your browser with your own key instead.

2 · Fallback

OpenRouter

Used only if the primary endpoint above fails or isn’t configured. Create a key at openrouter.ai/keys.
