Policy Drafting & Gap Analysis

What This Does

Policy Drafting & Gap Analysis uses AI to draft new or revised organizational policies from templates and regulatory requirements. When you provide an existing policy, the system compares it against standards and frameworks to produce a gap analysis with prioritized remediation recommendations.

Select a policy type (Data Privacy, Information Security, Acceptable Use, BYOD, Incident Response, or Vendor Management), specify your regulatory framework (e.g., GDPR, SOC 2, ISO 27001), and describe your organization. The AI generates a compliant policy draft and, if you upload or paste an existing policy, identifies gaps with severity ratings and actionable recommendations.

Example User Journey

1
Select Policy Type & Framework

Compliance selects "Data Privacy" and enters "GDPR" as the regulatory framework. She describes the organization and any specific requirements.

2
Provide Existing Policy (Optional)

She uploads the current data privacy policy (PDF or DOCX) or pastes its text. This enables gap analysis against the chosen framework.

3
AI Generates Draft & Gap Report

The system produces a coverage score (1–100), a full policy draft with sections, and a gap analysis table with severity and recommendations.

4
Review and Remediate

General counsel reviews the draft and gap report. Critical and high-severity gaps are prioritized for updates before approval and publication.

Data Flow Summary

  1. User completes the form (policy type, framework, org description, requirements) and optionally uploads or pastes existing policy text.
  2. The browser extracts text from uploaded files (TXT, PDF, DOCX) and sends form data plus policy text to the API Proxy.
  3. The API Proxy forwards the request to the NAI chat completions endpoint.
  4. NAI drafts the policy and performs gap analysis, returning structured JSON (coverageScore, policyDraft, gaps, complianceNotes).
  5. The Portal UI renders the coverage score, policy draft, gap analysis table, and recommendations.
  6. Policy metadata is saved for audit and history tracking.

Architecture Overview

How It Works

The Portal UI collects policy type, regulatory framework, organization description, and optional existing policy text (via file upload or paste). The API Proxy forwards requests to the Nutanix AI chat completions endpoint. The LLM drafts the policy and performs gap analysis, returning structured JSON. Results are rendered as a coverage score, formatted policy draft, gap analysis table, and compliance notes.
