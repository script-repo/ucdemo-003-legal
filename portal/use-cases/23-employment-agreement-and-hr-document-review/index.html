Employment Agreement Review

What This Does

Employment Agreement Review uses AI to automatically analyze employment agreements and HR documents. The system extracts key terms (compensation, non-compete, severance, IP assignment), scores overall risk, and flags issues that deviate from standard practice. Instead of spending hours on first-pass review, employment counsel and HR can get a structured breakdown in seconds: risk score, key terms table, restrictive covenant analysis, and actionable recommendations.

Upload an offer letter, employment agreement, separation agreement, or other HR document. The AI identifies compensation structure, non-compete scope and duration, severance terms, IP assignment clauses, and jurisdiction-specific considerations — all presented in a clear format for immediate review and action.

Example User Journey

1
Upload or Paste

HR receives an executive employment agreement. They drag the PDF into the upload zone — or paste the text directly.

2
AI Analyzes

The system extracts the text, sends it to the Nutanix AI inference endpoint, and receives a structured analysis in seconds.

3
Review Results

A risk score of 65 / Medium appears. The key terms table shows compensation, non-compete scope, and severance. Restrictive covenants are assessed for enforceability. Issues are flagged with severity and recommendations.

4
Act on Recommendations

Employment counsel reviews the flagged issues and restrictive covenant analysis. They apply recommendations and send the revised document for execution — reducing review time from hours to minutes.

Data Flow Summary

  1. User uploads an employment document (TXT, PDF, DOCX) or pastes text via the Portal UI.
  2. The browser extracts the text content and sends it to the API Proxy.
  3. The API Proxy forwards the request (with authentication) to the NAI chat completions endpoint.
  4. NAI analyzes the document and returns a structured JSON response with risk score, key terms, restrictive covenants, issues, and jurisdiction notes.
  5. The Portal UI renders the results: risk score badge, summary, key terms table, restrictive covenants, issues list, and jurisdiction notes.
  6. Analysis metadata is saved to PostgreSQL for audit and history tracking.

Architecture Overview

How It Works

Platform Infrastructure

The entire solution runs on Nutanix AHV, a secure enterprise-grade hypervisor. On top of AHV, NKP (Nutanix Kubernetes Platform) provisions and manages the Kubernetes environment for all application workloads.

Kubernetes Workloads (ntnx-use-cases namespace)

All use-case components are deployed as pods within the ntnx-use-cases namespace:

  • Portal UI — Static front-end providing the document upload interface, architecture visualization, and analysis results display.
  • API Proxy (server.py) — Server-side CORS proxy that routes browser requests to the Nutanix AI endpoints.
  • PostgreSQL 16 (pg-db) — Stores analysis metadata, audit logs, and user activity.
  • ChromaDB (ch-db) — Vector database for clause embeddings and semantic search.

AI & Inference (Nutanix AI — NAI)

Nutanix AI (NAI) provides the inference endpoints. When an employment document is uploaded, the text is sent with a structured system prompt. The model returns JSON containing risk score, key terms (compensation, non-compete, severance, IP assignment), restrictive covenant analysis, issues, and jurisdiction notes.
