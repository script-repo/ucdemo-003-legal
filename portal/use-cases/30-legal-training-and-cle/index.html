Legal Training & CLE

What This Does

Legal Training & CLE uses AI to generate personalized training materials, CLE content, and practice-area assessments. Specify a topic, practice area, audience level, and format — the system produces structured training content including learning objectives, key takeaways, assessment questions with explanations, and recommended resources. Content is tailored to your firm's practice areas and keeps attorneys current on regulatory and competency requirements.

Whether you need a full CLE presentation, a quick reference guide, a training module, or an assessment quiz, the AI generates professional content in seconds. Use it for ethics training, practice-area updates, compliance education, or onboarding new associates.

Example User Journey

1
Configure Training

An L&D manager enters a topic (e.g., "Ethics in E-Discovery"), selects Litigation as the practice area, Associate as the audience level, and CLE Presentation as the format. She adds specific focus areas in the textarea.

2
AI Generates Content

The system sends the form data to the Nutanix AI inference endpoint. The model produces structured JSON with sections, learning objectives, assessment questions, and recommended resources.

3
Review Results

The training content appears in formatted sections with key points, learning objectives, and key takeaways. Assessment questions include multiple-choice options, correct answers, and explanations.

4
Use or Export

The L&D manager reviews the content, copies sections into a slide deck or LMS, and uses the assessment questions for CLE credit verification or competency tracking.

Data Flow Summary

  1. User completes the form (topic, practice area, audience level, format, focus areas) in the Portal UI.
  2. The browser sends the form data to the API Proxy.
  3. The API Proxy forwards the request (with authentication) to the NAI chat completions endpoint.
  4. NAI generates structured JSON with title, summary, learning objectives, sections, assessment questions, key takeaways, and recommended resources.
  5. The Portal UI renders the results: formatted training content, learning objectives list, assessment questions, and recommended resources.
  6. Training metadata is saved to PostgreSQL for audit and history tracking.

Architecture Overview

How It Works

Platform Infrastructure

The solution runs on Nutanix AHV and NKP (Nutanix Kubernetes Platform), providing container orchestration and lifecycle management for all application workloads.

Kubernetes Workloads (db-project-003 namespace)

All use-case components are deployed as pods within the db-project-003 namespace:

  • Portal UI — Static front-end providing the training configuration form, architecture visualization, and results display.
  • API Proxy (server.py) — Server-side CORS proxy that routes browser requests to the Nutanix AI endpoints.
  • PostgreSQL 16 (pg-db) — Stores training metadata, audit logs, and user activity.

AI & Inference (Nutanix AI — NAI)

Nutanix AI (NAI) provides the Chat Completions endpoint. Form data (topic, practice area, audience level, format, focus areas) is sent with a structured system prompt. The model returns JSON containing title, summary, learning objectives, sections with key points, assessment questions with options and explanations, key takeaways, recommended resources, and estimated duration.
