Patent Drafting & Prior Art

What This Does

Patent Drafting & Prior Art uses AI to assist with patent claim drafting and prior art identification. Enter your invention details — title, technology field, description, key features, and any known prior art — and the system generates a structured draft of patent claims, assesses novelty, and identifies relevant prior art references with overlap and distinction analysis.

This tool accelerates the drafting cycle for patent attorneys and inventors by producing a first draft of claims and a prior art report in seconds. Attorney oversight remains essential for inventorship, strategy, and final filing decisions.

Example User Journey

1
Describe Invention

An inventor or patent attorney enters the invention title, selects the technology field (Software, Mechanical, Chemical, Biotech, Electrical, or Materials), and provides a detailed description plus key features and any known prior art.

2
AI Drafts Claims

The system sends the disclosure to the Nutanix AI inference endpoint, which generates a structured draft with independent and dependent claims, an abstract, and technology classification.

3
Review Prior Art

The AI identifies prior art references with relevance scores, overlap descriptions, and distinctions. A novelty score (1–100) indicates the assessed strength of the invention relative to known art.

4
Refine Application

Use the suggested improvements to strengthen claims, narrow scope, or address prior art. Save drafts to history and iterate until ready for formal filing.

Data Flow Summary

  1. User completes the invention form (title, tech field, description, features, known prior art) in the Portal UI.
  2. The browser sends the form data to the API Proxy.
  3. The API Proxy forwards the request (with authentication) to the NAI chat completions endpoint.
  4. NAI generates draft claims, prior art analysis, novelty score, and suggestions in structured JSON.
  5. The Portal UI renders the results: novelty score, claims list, prior art cards, and suggestions.
  6. Draft metadata is saved to PostgreSQL for audit and history tracking.

Architecture Overview

How It Works

Platform Infrastructure

The solution runs on Nutanix AHV and NKP (Nutanix Kubernetes Platform). The Portal UI, API Proxy, and PostgreSQL are deployed as pods within the db-project-003 namespace.

AI Inference (Nutanix AI — NAI)

Nutanix AI (NAI) provides the chat completions endpoint. When the user submits the invention form, the data is sent with a structured system prompt that instructs the model to return JSON containing novelty score, title, abstract, claims (independent and dependent), prior art references with relevance and overlap, suggestions for improvement, and technology classification.

Data Persistence

Draft metadata and results are stored in PostgreSQL for audit and history. Users can recall previous drafts from the Recent Drafts list.
