Matter Budgeting & Pricing

What This Does

Matter Budgeting & Pricing uses AI to generate detailed budget estimates and pricing for legal matters based on matter type, complexity, and scope. Enter the matter details in the form — including type (Litigation, Corporate, IP, Real Estate, or Employment), complexity level, scope description, jurisdiction, estimated duration, and any special considerations. The AI produces a structured budget with phases, tasks, hours, rates, and amounts, plus assumptions and risk factors to support confident client pitches and matter planning.

Data Flow Summary

  1. User enters matter details (type, complexity, scope, jurisdiction, duration, special considerations) via the form.
  2. The browser sends the form data to the API Proxy.
  3. The API Proxy forwards the request (with authentication) to the NAI chat completions endpoint.
  4. NAI generates a structured JSON response with totalBudget, summary, phases (tasks, hours, rates, amounts), assumptions, and risks.
  5. The Portal UI renders the results: total budget display, summary, phases table, assumptions list, and risks.
  6. Budget metadata is saved to PostgreSQL for audit and history tracking.

Architecture Overview

How It Works

Platform Infrastructure

The entire solution runs on Nutanix AHV, a secure enterprise-grade hypervisor. On top of AHV, NKP (Nutanix Kubernetes Platform) provisions and manages the Kubernetes environment for all application workloads.

Kubernetes Workloads (ntnx-use-cases namespace)

All use-case components are deployed as pods within the ntnx-use-cases namespace:

  • Portal UI — Static front-end (HTML, CSS, JavaScript) providing the matter budgeting form, architecture visualization, and budget results display.
  • API Proxy (server.py) — CORS proxy that routes browser requests to the Nutanix AI endpoints with bearer token injection.
  • PostgreSQL 16 (pg-db) — Stores budget metadata, audit logs, and user activity. Data persisted on Nutanix Volumes PVC.
  • ChromaDB (ch-db) — Optional vector store for matter embeddings and similar-matter RAG.

AI & Inference (Nutanix AI — NAI)

Chat Completions (llama3-1-8b) — The LLM receives matter details (type, complexity, scope, jurisdiction, duration, special considerations) and returns a structured JSON budget with totalBudget, summary, phases (tasks, hours, rates, amounts), assumptions, and risks.
